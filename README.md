# HugeGraph Agent Skills

面向开发者的共享技能仓库。独立 skill 放在 `skills/<名称>/`，为已有 skill 增加能力的文件放在 `extensions/<名称>/`。每项说明自己的安装方式、使用范围和来源。

| 项目 | 用途 | 安装 |
| --- | --- | --- |
| [Codex imagegen 的 PR 配图扩展](extensions/imagegen/README.md) | 给已有 `imagegen` 增加 PR 配图与 GIF 流程 | [固定试用版安装 Prompt](https://github.com/hugegraph/skills/blob/imagegen-preview-v0.1.0/extensions/imagegen/README.md#安装)。安装后在技能选择器中核对只有一个 `imagegen`。 |

新增或更新时，请附上独立的安装说明、使用例子与验证结果。详见 [贡献说明](CONTRIBUTING.md)。
